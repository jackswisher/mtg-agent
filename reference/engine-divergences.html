Known engine divergences

Where rules.py departs from the Comprehensive Rules. A running list — append as you find more.

Every entry here is a false lesson available to a trained policy. Status is open until a regression test pins the correct behaviour.

#DivergenceCRSite
D1 Two damage systems. Combat damage is a local dict in _execute_combat_damage; spell damage is a Card attribute. Neither reads the other, so damage from different sources never sums to lethal. 510.1a, 704.5g rules.py:1389, rules.py:3463
D2 Damage never wears off. Cleanup clears temporary P/T but not damage_marked, despite the comment claiming it does. Spell damage persists for the whole game. 514.2 rules.py:1840 (_execute_cleanup)
D3 SBAs run only in combat. One call site, inside combat damage. Elsewhere, lethal is caught by ad-hoc inline checks that each new card effect must remember to re-implement. 704.3 rules.py:1440 (only caller)
D4 SBA docstring overstates the body. Advertises 5 checks, implements 2. Missing: lethal damage, counter annihilation, unattached auras. 704.5 rules.py:1791
D5 No layer system. _get_effective_power_toughness applies base, counters, and current_power deltas in a fixed ad-hoc order. Fine for the current 56 cards; breaks on any real layer interaction. 613 rules.py:2438
D6 Minor: no priority window in the combat damage step, and no end-of-combat step. 510.4, 511 rules.py:67 (PRIORITY_PHASES)

Reproductions

D1 — a 1/1 attacks into a 2/2 already carrying 1 spell damage:

import random
from mtg.env.rules import RulesEngine
from mtg.env.card_definitions import create_card_instance
from mtg.env.deck_archetypes import get_archetype

eng = RulesEngine(random.Random(0))
mk = lambda: get_archetype('mono_red_aggro').build_deck()

st = eng.initialize_game(mk(), mk())
atk = create_card_instance('Phoenix Chick', 9003); atk.summoning_sick = False
dfn = create_card_instance('Goblin Guide', 9004)
st.players[0].battlefield.append(atk)
st.players[1].battlefield.append(dfn)
dfn.damage_marked = 1
st.active_player = 0
st = eng.declare_attackers(st, [atk.card_id])
st = eng.declare_blockers(st, {atk.card_id: dfn.card_id})

assert not any(c.card_id == dfn.card_id for c in st.players[1].battlefield), \
    "D1: blocker should have died to 1 spell + 1 combat damage"
# currently FAILS - the blocker survives

D2 — damage survives the cleanup step:

c.damage_marked = 1
for _ in range(3):
    st = eng._execute_cleanup(st)
assert getattr(c, 'damage_marked', 0) == 0, "D2: cleanup should remove damage"
# currently FAILS - still 1

Suggested fix order

D1, D2, and D3 are one fix, not three: a single persistent damage field on Card, cleared in _execute_cleanup, with lethal checked by _check_state_based_actions called wherever a player would gain priority. D4 falls out of that. D5 is a much larger job and only matters once the card pool grows.
