The one architectural fact

Nearly every RulesEngine method has the shape (GameState, args) -> GameState. Hence MTGEnv.step() reads as a long dispatch table: decode an int into the right verb, reassign self.state.

The two contracts you must not break

ContractValueEnforced in
Observation dimension3077observation.py / ObservationConfig
Action space size478action_mask.py / ActionIndexMap

Coupled: every hand slot the action mask can address must also be visible in the observation. mtg_env.py asserts this at construction (comment at line 116). Raising a hand cap on one side without the other is the classic way to break this repo.

The 478 actions

  0        PASS
  1–2      KEEP_HAND / MULLIGAN
  3–5      PLAY_LAND[0-2]
  6–10     CAST_SORCERY[0-4]        sorcery speed, your main phase
 11–15     CAST_INSTANT[0-4]        any priority window
 16–35     ATTACK_TOGGLE[0-19]      + confirm
 36–55     BLOCK_SELECT_ATTACKER[0-19]
 56–75     BLOCK_SELECT_BLOCKER[0-19]
 76+       bottom / discard / activate / target / mana-source slots
                        (exact offsets: ActionIndexMap properties)

Don't hardcode these offsets. play_land_start, cast_instant_start, and friends are computed properties on ActionIndexMap.
